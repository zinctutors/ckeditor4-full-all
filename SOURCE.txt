The local archive includes upstream core, plugin and skin sources, notices,
and build scripts. Runtime output omits samples/ and codesnippetgeshi/ even
though their upstream sources remain in the source archive.

From a package checkout, rebuild with Java 17, Python 3, Bash, tar, sha256sum, and curl:
  bash scripts/rebuild.sh /path/to/new-output-directory

The output directory must not already exist. The script downloads and verifies
CKBuilder 2.4.3; alternatively set CKBUILDER_JAR to a local copy. It never
replaces the repository's runtime. See README.md for details. CKBuilder's
cache timestamp varies with build time; byte-identical output is not promised.
The build tool is not included in this distribution.

Dated changes by zinctutors
--------------------------

2026-11-02: Created the repository's first version as a custom build from the
upstream revision above using CKBuilder 2.4.3. The compiled plugin selection
follows CKSource's CDN full-all 4.22.1 build except that Export to PDF and
SCAYT are excluded entirely.

from upstream dev/builder/build-config.js with the selection and exclusions
documented above. Samples and codesnippetgeshi remain excluded from runtime.
